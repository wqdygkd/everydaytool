everydaytool 1.1.0 绿色版
======================

1) 免安装直接用：双击 everydaytool.exe
2) 安装到本用户（不需要管理员，不经过 NSIS/MSI）：
   双击 install.cmd
   → 复制到 %LOCALAPPDATA%\everydaytool
   → 开始菜单、桌面创建快捷方式
   → 「设置 → 应用」里生成 everydaytool 卸载项
   安装包报 "Can't write: ...everydaytool.exe" 时用这条路径。
3) 卸载：设置 → 应用 → everydaytool → 卸载

用户数据在 %APPDATA%\everydaytool（其中窗口外观、窗口大小与位置在新版里位于 <数据目录> 下）。
