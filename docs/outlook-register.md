# Outlook 注册

单账号的 Outlook 注册资料生成与收件工具。**软件内不加载注册页**：注册资料（邮箱、密码、姓名、生日、辅助邮箱）在这里生成并复制，注册在外部浏览器完成；注册成功后把资料保存到账号库，再用「邮箱」子视图打开收件箱。

## 边界

- **不加载注册页面**：注册子视图没有 webview，也没有外部打开按钮；`outlook.live.com/...?prompt=create_account` 不会在应用内出现。
- **不注入任何内容**：没有 preload，不调用 `executeJavaScript`，不读取或改写页面 DOM，不做自动填表 / 自动点击 / 验证码处理。
- **不做自动注册、接码、代理池、并发**：参考项目 `LainsNL/OutlookRegister` 的反检测浏览器与验证码自动化没有搬进来。
- 收件箱是独立的持久分区 webview；账号之间互不影响，注册成功后打开邮箱不需要重新登录。
- 收件界面就是 Outlook 网页版本身；没有对接 Microsoft Graph / IMAP。

## 收件箱浏览器环境

只有「邮箱」子视图会加载页面：

- webview 显式设置 `contextIsolation=yes,nodeIntegration=no,sandbox=yes`，没有 preload；页面里的 `window` 就是普通网页环境。
- 允许页面弹窗（`allowpopups`），避免 OAuth / 条款页被拦截。
- 主进程只做两件事：
  1. 把 User-Agent 里的 Electron token 去掉，按运行时 Chromium 版本伪装成普通 Chrome（微软登录页会拒绝带 Electron 标识的嵌入浏览器）；
  2. 按设置应用代理。
- 这两项都是网络层设置，不会向页面注入脚本或样式。

## 数据

| 数据 | 落点 | 说明 |
| --- | --- | --- |
| 账号库 | `<config>/outlook-register/accounts.json` | 邮箱、资料、状态、备注；密码为系统加密信封 |
| 注册草稿 | `<config>/outlook-register/draft.json` | 单个进行中的草稿，密码同样为信封 |
| 设置 | `<config>/outlook-register/settings.json` | 默认后缀、代理、复杂密码规则 |
| 登录态 | `session/Partitions/outlook-register-<id>/` | Chromium 拥有；删除账号或「清除登录会话」时清空 |

清理缓存不会删除账号；配置层条目已标 `sensitive`，备份导出时按凭据提示。

## 使用

1. 首次打开工具时生成草稿：随机邮箱本地部分（12–14 位）、强密码、英文姓名、出生日期。密码默认 16 位，含大写 / 小写 / 数字 / 符号。
2. 用左侧的复制按钮取出邮箱与密码；需要调整密码时打开「生成复杂密码」，规则保存在设置里，只影响之后生成的密码。
3. 在系统浏览器里打开 Outlook 注册页，用这些资料完成注册。
4. 注册成功后回到工具，点「保存到账号库」，草稿转为账号。
5. 切到「邮箱」子视图，右侧始终是邮箱页面；左侧账号卡可点箭头向下展开资料，添加账号后会自动展开。
6. 展开区可编辑邮箱、密码（留空表示不改）、辅助邮箱、状态与备注；表单直接写回账号库，密码重新走系统加密信封。
7. 账号操作还包括复制邮箱 / 密码、标记已注册 / 待确认、清除登录会话、删除账号。

页面结构、选择器和微软改版都与注册资料页无关：这里没有需要跟进的选择器，也没有需要回归的注入逻辑。

## 验证

```bash
pnpm test
pnpm typecheck
pnpm data-layers:check
```

手工验收：

1. 生成草稿，确认邮箱后缀切换后草稿邮箱同步变化。
2. 确认「注册」子视图不再出现任何 Outlook 页面或「打开注册页」入口。
3. 保存草稿后确认左侧出现账号并自动展开资料，右侧能加载收件箱。
4. 在左侧展开区改备注与辅助邮箱，保存后重启工具仍然生效。
5. 清除登录会话后重新打开邮箱，确认回到登录页，需要重新登录。

## 已知坑

- 注册成功率取决于出口 IP；同一 IP 短时间重复注册会被微软限制。工具不绕过，也不会自动重试。
- Microsoft 登录页可能识别过于陈旧的 Chrome UA；UA 使用运行时 Chromium 版本，升级 Electron 后自动更新。
- 会话分区属于 Chromium 会话层，设置页「清缓存」里的会话缓存清理可能让账号退出登录，需要重新登录。
