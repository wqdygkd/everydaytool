设计意图

不把每个仓库做成卡片：组头承担仓库身份与批量动作，子行承担技能状态与来源。这样一屏能扫完「哪个仓库有问题、问题是什么、下一步点哪里」。未托管行默认只读，接管是显式授权，不是静默写锁。

设计令牌

primary strong success warning error raised

强调色只承担动作、选中与焦点；状态色只承担状态。表头 / 元信息 11px，表体 12px，路径 11px mono。

布局规则

  • 左轨 68px，主工作区左右 18px；工具页只保留一个 ToolSurface。
  • 工具头 70px：40px 图标 + 17px 标题 + 单行状态；动作不超过「主 + 次 + 更多」。
  • 主表列：技能 46% / 状态 14% / 来源 26% / 操作 14%；行高 45px，组头 42px。
  • 不用卡片包表格；组头用 fill 底，子行只靠缩进、边线和状态点建立层级。

不要做

  • 不要把仓库组做成独立卡片，也不要在 ToolSurface 里再套 UiPanel。
  • 不要给每个工具分配独立品牌色；状态色只用于状态。
  • 不要用弹窗承载「查看详情」这类不需要打断的任务。

状态与交互

状态必须「点 + 文字」同时出现；危险动作才用红色实底，普通失效用 warning 文案。

目录存在、远端存在、内容匹配基线。

上游已移除

远端快照没有此路径；默认进回收站并从锁移除。

本地已修改

本地 hash 与基线不同；覆盖前必须确认。

已禁用

目录移出扫描根；仍在选择集里，可随时启用。

已移除

锁和目录都没了，但 registry 墓碑保留 origin；可重装或遗忘。

未托管

来源未知；默认只读，可收藏、接管、删除，不能更新或禁用。

交互

  • 点组头折叠 / 展开；星标切换收藏；行操作保持 hover 才显现。
  • 「管理技能」打开仓库面板：全部技能、已选自动勾选、改选后一次应用。
  • 「更新此仓库」只列已选技能的更新 / 失效 / 冲突。
  • 「预设」可把一份期望清单装到全局 / 项目 / 指定目录；默认增量，精确模式需确认。
  • 「已移除」是墓碑，不是技能目录；重新安装优先恢复回收站副本。
  • 未托管默认只读；「接管」里可选绑定来源（写锁）或仅本地（不写锁）。
  • 「设计信息」按钮打开本抽屉；关闭后回到纯工具预览。

维护注意

  • 新增状态先改 skill-manager-plan.md §7.3，再改 UI。
  • 不要新增颜色；状态色从 tokens 取，保持单档语义色。
  • 删除、禁用、卸载都必须可恢复；预设不写锁，应用成功才写。
  • 墓碑是元数据，不随回收站清理；「遗忘」必须二次确认。
